## 추천 읽기 순서

1. 저장소를 처음 볼 때는 `아키텍처`와 `모듈 가이드`를 먼저 읽습니다.
2. 바로 사용 흐름을 보고 싶다면 `예시`를 이어서 봅니다.
3. SPI를 직접 구현할 계획이라면 `SPI/extension 가이드`를 봅니다.
4. 테스트, CI, 배포 흐름이 필요하면 `테스트/CI 가이드`를 봅니다.
5. 문제를 좁혀야 할 때는 `트러블슈팅`을 봅니다.
